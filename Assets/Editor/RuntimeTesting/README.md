# Unity Editor 런타임 테스트

1. **Tools → Testing → Runtime Test**로 창을 엽니다.
2. 게임 씬을 Play Mode에서 실행합니다. 타이틀에서 게임을 시작해도 됩니다.
3. 현재 날짜·시간과 진행 상태를 확인하고, 원하는 시·분을 입력한 뒤 **시간 적용**을 누릅니다.
4. **06:00으로 이동**하면 정상적인 근무 종료 흐름과 하루 종료 보고서를 시험할 수 있습니다. 시작 안내나 매뉴얼 확인으로 게임이 대기 중이면 그 단계가 끝난 뒤 종료 흐름이 시작됩니다.
5. **실행할 현상**에서 항목을 고르고 **선택한 현상 즉시 실행**을 누릅니다. 현재 게임 씬의 일반·특수 이상현상 풀을 사용하며, 실제 게임의 관리 목록에 등록됩니다.

**시간 흐름 일시정지**는 게임 시간과 이상현상 타이머·안정도 감소를 멈춥니다. 현상 자체의 애니메이션이나 소리는 계속될 수 있습니다. **자동 이상현상 발생 정지**는 무작위 발생을 막으며 직접 선택한 현상은 실행할 수 있습니다. **활성 이상현상 해결**은 모든 활성 현상의 정상 해결 처리를 호출해 현상과 관리 목록을 정리합니다.

같은 현상·같은 방의 일반 현상은 중복 실행할 수 없습니다. 일반 현상은 최대 두 개, 특수 현상은 최대 한 개입니다. 근무 종료·게임 오버 후에는 새 현상을 실행할 수 없으며, 근무 종료 후 시간을 되돌릴 수도 없습니다. 반복 테스트는 보고서에서 다음 날로 진행하거나 Play Mode를 다시 실행하세요.

창을 닫아도 지정한 현재 런타임 상태는 유지됩니다. Play Mode를 종료하면 시간·활성 현상·정지 설정이 사라집니다. 씬과 ScriptableObject를 저장하거나 수정하지 않습니다. 창의 시·분 입력과 선택 항목 이름은 Editor 창 상태로만 유지됩니다.

`RuntimeTestWindow.cs`, UXML, USS는 `Assets/Editor`에 있으며, `DaySystem`·`AnomalySystem`의 테스트 API는 `#if UNITY_EDITOR` 내부에 있습니다. 따라서 Development 빌드에서도 테스트 기능은 포함되지 않습니다.
